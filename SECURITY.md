## Как сообщить об уязвимости

**Не создавайте публичный issue для уязвимости.**

Используйте GitHub **Private Vulnerability Reporting**:
`Security` → `Report a vulnerability` в репозитории, либо приватное security
advisory. Ответ — в течение 72 часов, исправление — по критичности.

## Модель угроз (кратко)

- Транспорт: только HTTPS/WSS в проде (Caddy, авто-TLS). HTTP наружу закрыт.
- Аутентификация: JWT HS256, TTL 7 дней, секрет обязателен в проде
  (fail-fast при дефолтном значении).
- Rate-limit: глобальный, заголовки draft-7; лимит настраивается `RATE_LIMIT_MAX`.
- Файлы: размер ограничен `MAX_FILE_SIZE`, имена санитизируются, раздача
  только из каталога uploads.
- WS: токен обязателен при апгрейде, невалидный → close 4401; подписки
  проверяются членством в комнате.
- Сообщения: идемпотентность `clientMessageId` закреплена уникальным индексом
  в БД (защита от двойной доставки/ретраев).
